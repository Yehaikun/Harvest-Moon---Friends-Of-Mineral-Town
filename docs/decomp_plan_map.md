# 地图系统反编译计划

目标：把 map 系统中的 13 个函数从汇编转成 C++，
反编译后你能像开发者一样理解地图加载、渲染、覆盖层逻辑。

## 方法

```
每个函数：
  1. Ghidra 打开 fomt.gba
  2. 跳转到函数地址（如 0x080A6640）
  3. 看反编译的 C 伪代码
  4. 在 src/ 新建 .cc 文件
  5. 写 C++ 实现
  6. 从 Makefile 去掉对应的 .s 文件
  7. make -j2 fomt.gba 验证通过
```
