二、实验记录 (基于 MapData 和 terrain 的改动测试)
-------------------------------------------------

实验1: 扩农场边界
- 操作: MapData.width 60→240, height 56→240
- 结果: 画面无变化
- 结论: 单改 width/height 不够, terrain_map 数据大小不变

实验2: fence 碰撞 bit0 验证
- 操作: terrain_info[5].bit0 = 1→0 (围栏值=5, 1095块)
- 结果: 围栏变可走(用户确认)
- 结论: terrain_info bit0 确实控制碰撞 ✅ 已验证可用

实验3: 农场视觉替换为南镇 packed_img
- 操作: farm.MapData.packed_img → south_town.packed_img
- 结果: 农场画面无变化, 反而玫瑰广场异常
- 结论: packed_img 不是简单视觉tilemap指针, 映射关系更复杂


三、已验证的地图碰撞链路
--------------------------
GetMapData(map_id) @ 0x080A4698
  ├── MapData +0x18: terrain_info → terrain属性数组 (bit0=碰撞)
  ├── MapData +0x1C: terrain_map → 每格terrain索引 (w*h字节)
  ├── MapData +0x20: width (tile数)
  ├── MapData +0x22: height (tile数)
  ├── MapData +0x24: is_interior
  └── MapData +0x00~0x14: packed_img/pal/tiles (视觉资源, 链路未完全确认)
